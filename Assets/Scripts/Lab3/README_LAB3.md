# Лабораторна робота 3 — просторові інтерфейси (Spatial UI) та покрокові форми

Стек: Unity 6000.5.9f1, **XR Interaction Toolkit 3.6.1** + OpenXR 1.18.0, тестування без шолома —
штатний **XR Interaction Simulator** із семплів XRI.

Наскрізна тема лабораторних з 3-ї: **VR-симулятор огляду та дефектоскопії газопроводу** —
візуалізація тиску в трубах, робота з регулювальними вентилями та звіт про витік.
У цій роботі звіт зберігається локально; передача на сервер — наступна лабораторна.

## Як запустити

1. Відкрити проєкт в Unity 6000.5.9f1.
2. Меню **Lab3 → 1. Setup XR Project** — імпорт семплів `Starter Assets` і `XR Interaction Simulator`
   (ті самі вимоги, що й у лабораторній 2, тому крок делегується наявному інсталятору).
3. Меню **Lab3 → 2. Build Spatial UI Scene** — генерується сцена `Assets/Scenes/Lab3_SpatialUI.unity`.
4. Натиснути Play (фокус на вікні Game).
5. Меню **Lab3 → 3. Validate Scene** — перевірка сцени за пунктами завдання (друкує звіт у Console).
6. Меню **Lab3 → 5. Capture Screenshots** — три рендери сцени у `Screenshots/` для звіту.

## Керування (XR Interaction Simulator, без шолома)

| Дія | Клавіші |
|---|---|
| Відкрити/закрити планшет оператора | `M` (кнопка Menu контролера) |
| Вибір пристрою | `[` — ліва рука, `]` — права рука, `H` — голова, `Tab` — цикл |
| Рух / огляд | `W` `A` `S` `D`, `E` / `Q`; огляд — права кнопка миші + рух миші |
| Промінь по UI, клік | навести променем і натиснути `T` (Trigger) |
| Прямий дотик (Poke) | підвести руку впритул до кнопки консолі — спрацьовує без Trigger |
| Перемкнути вентиль на трубі | навести промінь і натиснути `G` (Grip / Select) |
| Взяти / штовхнути | `G` (Grip), стік — `I` `J` `K` `L` |

**Введення тексту у форму.** У симуляторі кожна латинська літера — це окрема дія
(`W` `A` `S` `D` — рух, `M` — меню планшета, `T` — Trigger, `G` — Grip, `Tab` — зміна пристрою),
тому поки активне поле введення, `FormInputLock` вимикає симулятор, провайдери локомоції
та гарячу клавішу планшета. Вийти з поля: `Enter` або клік по вільному місцю панелі.

## Відповідність завданням

| Завдання | Реалізація |
|---|---|
| World-Space Canvas-панель перед користувачем, що відкривається за запитом | `SpatialTablet` — панель `Spatial Tablet/Panel` вимкнена на старті; `InputAction` на `<XRController>/menuButton` + `<Keyboard>/m` відкриває її й ставить перед камерою на 0.7 м |
| Взаємодія дистанційним вказівником (Ray Interactor) | `NearFarInteractor` з префаба `XR Origin (XR Rig)` + `TrackedDeviceGraphicRaycaster` на кожному канвасі + `EventSystem` з `XRUIInputModule` |
| Взаємодія прямим дотиком (Direct Poke) | `XRPokeInteractor` на обох контролерах рига; кнопки консолі `Pipeline Console` стоять на висоті руки і натискаються пальцем |
| Спливаючі інформаційні картки при наведенні/виділенні 3D-об'єкта | `EquipmentInfoCard` на трьох ділянках труби і двох вентилях: показується на `hoverEntered`, тримається поки об'єкт виділено, текст бере з `IEquipmentInfo` (актуальний тиск і стан), картка розвернута до користувача |
| Заповнення форми: перемикачі, слайдери, поля введення, збереження/скидання | `LeakReportForm`: 2 × `InputField` (ID ділянки, оператор), 3 × `Toggle` (витік, падіння тиску, корозія), 2 × `Slider` (тиск 0–120 бар, критичність 1–5), кнопки **Зберегти**, **Скинути**, **Зчитати з мережі** |
| Блокування керування під час набору тексту | `FormInputLock` вимикає `XRInteractionSimulator`, усі `LocomotionProvider` і гарячу клавішу планшета, поки сфокусоване `InputField`; підказка про режим виводиться просто на формі |
| Валідація введених даних | `LeakReport.Validate()` — порожні поля, довжина ID, діапазони тиску й критичності, хоча б одна ознака дефекту; помилка показується в статусному рядку форми |
| Покроковий візард (Wizard / State Machine) | `InspectionWizard` — стани `Idle / Step / Finished`, 6 кроків (`InspectionProgram`): інструктажі та 3 контрольні питання, перевірка відповіді, навігація **Назад / Далі / Спочатку** |
| Фіксація фінального результату | екран результату: кількість правильних відповідей, прохідний бал (60 %), вердикт «зараховано / не зараховано», кнопка переходу до звіту |
| Тестування без шолома через емульований лазерний промінь | `XR Interaction Simulator` у сцені; усі канваси — World Space з `TrackedDeviceGraphicRaycaster`, тож промінь і клік `T` працюють у редакторі |

## Тематичне наповнення

| Елемент теми | Реалізація |
|---|---|
| Візуалізація тиску в трубах | `PipelineNetwork` рахує тиск по трьох ділянках; `PipelineSegment` фарбує труби через `MaterialPropertyBlock`: синій — тиск впав, зелений — номінал (62 бар), червоний — перевищення |
| Робота з регулювальними вентилями | `ValveControl` на двох вентилях — вибір променем або дотиком перемикає «відкрито/перекрито», штурвал провертається на 90°, мережа одразу перераховує тиск (відсікання нижче за течією + підпір перед вентилем) |
| Звіт про витік | кнопка **Імітувати витік** на консолі вмикає аварію; **Зчитати з мережі** підтягує ID ділянки й фактичний тиск у форму; `LeakReport` — незмінна модель звіту, готова до відправки на сервер у наступній роботі |
